# Learning Cards

Four layers per card: **L0** a twelve-year-old can follow → **L1** the mechanism → **L2** how to use it → **limit** when it fails. Gap evidence follows each cluster.

---

## c16 采样与分诊（4 件）— 证据：`temperature policy llm` 放宽复查后对口≈0（真空白）；HN：评测成本已达 agent 本体 5 倍（Tessary，1M traces 案例）

- **L60 每步档位策略**：L0 不是每一步都值得动用最大火力——它按步骤的难度和风险决定用多聪明的模型、想多深。L1 输入步骤特征（可逆性/影响面/历史失败率），输出档位（cheap/balanced/max），纯规则可解释。L2 断言=①可逆+低影响 → cheap、②不可逆+高影响 → max。
- **L61 廉价预筛**：L0 先用便宜的办法把 1000 份记录扫一遍，只把可疑的几份交给贵的仔细看——像保安先瞄一眼再决定要不要开包。L1 L1 分类器（关键词/规则/小模型）全量扫，只放行可疑子集给 L2 深审；输出召回率下界估计。L2 断言=①可疑集非空时通过、②规则表为空时显式报「无法分诊」而非放行全部。
- **L62 深挖配额**：L0 仔细看一份记录很贵，所以一天只许深挖固定几份，超过就得先说理由。L1 记录深挖次数与预算，超配额则要求附「为什么这份值得」字段，缺字段拒绝。L2 断言=①超配额+无理由 → 拒、②超配额+有理由 → 过。
- **L63 评测成本比**：L0 盯一个比值：检查作业花掉的钱 ÷ 干正事花掉的钱。检查比干活还贵 5 倍，就该换检查方式了。L1 输入两侧花费，算比值，超阈报警并给三条降本路径。L2 断言=①5.0 倍报警、②0.5 倍不报。
